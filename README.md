# 🧠 Focus Session Timer

A minimalist, distraction-free Pomodoro timer designed to help you get "one thing at a time" done. 

## ✨ Features

*   **Clean & Minimalist UI:** A calming dark mode interface designed to reduce eye strain and keep you focused.
*   **25-Minute Pomodoro:** Standard focus interval to maximize productivity.
*   **Simple Controls:** Easy-to-use "Start focus" and "Reset" buttons.
*   **Responsive Design:** Works perfectly on desktop and mobile devices.

## 🛠️ Tech Stack

*   **HTML5** - Structure (`index.html`)
*   **CSS3** - Styling (`style.css`)
*   **JavaScript (Vanilla)** - Timer logic and DOM manipulation (`index.js`)
